# EasyFrame

EasyFrame is a seamless, secure bridge between Figma and Roblox Studio. It allows developers to instantly convert Figma UI designs into native Roblox GUI elements without manually rebuilding them.

## Features
- **Local & Secure:** Runs entirely on your own computer. No design data is sent to external servers.
- **Roblox OAuth Integration:** Securely links your Roblox account to handle asset uploads and authorizations.
- **Seamless Sync:** Generate a 6-character code in Figma and paste it directly into Roblox Studio.

## Credits
